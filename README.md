## Deskripsi Praktikum
Praktikum 1 membahas tentang dasar-dasar HTML (HyperText Markup Language) yang digunakan untuk membuat dan menyusun sebuah halaman web. Pada praktikum ini dipelajari struktur dasar HTML serta penggunaan beberapa tag HTML untuk membuat dan mengatur isi halaman web.
Materi yang dipraktikkan meliputi pembuatan struktur dasar HTML, heading dan paragraph, formatting text, hyperlink, penambahan gambar, pembuatan list, dan penggunaan komentar dalam HTML. Praktikum ini bertujuan untuk memahami fungsi dari setiap tag dan mengetahui bagaimana kode HTML menghasilkan tampilan pada halaman web.

## Tujuan Praktikum
1. Memahami struktur dasar HTML.
2. Membuat heading dan paragraph.
3. Melakukan formatting text.
4. Membuat hyperlink.
5. Menambahkan gambar pada halaman web.
6. Membuat list menggunakan HTML.
7. Membuat komentar dalam HTML.
