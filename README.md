# JAWABAN
1.Deklarasi `<!DOCTYPE html>` berfungsi untuk memberi tahu browser bahwa dokumen yang dibuat menggunakan standar HTML5, sehingga browser dapat menampilkan halaman sesuai dengan aturan HTML yang berlaku.

2.Tag merupakan penanda yang digunakan untuk membentuk struktur HTML, sedangkan elemen merupakan keseluruhan bagian HTML yang terdiri dari tag dan isi. Sementara itu, atribut merupakan informasi tambahan yang digunakan untuk memberikan pengaturan atau keterangan tertentu pada sebuah tag.

3.ag `<p>` digunakan untuk membuat sebuah paragraf baru, sedangkan `<br>` digunakan untuk membuat perpindahan ke baris berikutnya tanpa membuat paragraf baru. Jadi, `<p>` lebih cocok digunakan untuk teks yang berupa paragraf, sedangkan `<br>` digunakan ketika hanya ingin membuat jarak atau pindah baris.

4.Atribut href berfungsi untuk menentukan alamat atau tujuan dari sebuah hyperlink. Ketika link tersebut diklik, browser akan membuka halaman atau alamat yang telah ditentukan pada atribut href.

5.Hyperlink internal digunakan untuk menghubungkan halaman atau bagian lain yang masih berada dalam website yang sama. Sedangkan hyperlink eksternal digunakan untuk menghubungkan halaman website yang berbeda atau berada di luar website yang sedang dibuat.

6.Atribut src berfungsi untuk menentukan lokasi atau sumber file gambar yang akan ditampilkan pada halaman web. Sedangkan atribut alt berfungsi memberikan teks alternatif yang dapat ditampilkan apabila gambar tidak berhasil dimuat.

7.Tag `<ul>` digunakan untuk membuat daftar yang tidak memiliki urutan tertentu, biasanya ditampilkan menggunakan tanda titik. Sedangkan `<ol>` digunakan untuk membuat daftar yang memiliki urutan, biasanya ditampilkan menggunakan angka.

8.Jika path gambar pada atribut src salah, browser tidak dapat menemukan file gambar tersebut sehingga gambar tidak akan tampil pada halaman web. Biasanya akan muncul tanda atau ikon yang menunjukkan bahwa gambar tidak berhasil dimuat.

9.Heading `<h1>` sampai `<h6>` perlu digunakan secara terstruktur agar tingkatan judul dan subjudul dalam halaman web menjadi jelas. Dengan struktur yang baik, isi halaman akan lebih rapi dan lebih mudah dipahami oleh pengguna.

10.Komentar <!-- ... --> digunakan untuk memberikan catatan atau keterangan pada kode HTML. Komentar tersebut tidak akan ditampilkan pada halaman web sehingga hanya dapat dilihat ketika kode HTML dibuka.
