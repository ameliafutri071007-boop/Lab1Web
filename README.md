## 1. Membuat Struktur Dasar HTML

Pada praktikum ini saya membuat struktur dasar HTML yang menjadi kerangka utama sebuah halaman web. Struktur dasar HTML diperlukan agar browser dapat mengenali dan menampilkan isi halaman dengan benar.

- `<!DOCTYPE html>` digunakan untuk memberi tahu browser bahwa dokumen yang dibuat menggunakan HTML5.

- `<html>` merupakan tag utama yang membungkus seluruh isi dokumen HTML.

- `<head>` digunakan untuk menyimpan informasi tentang halaman web yang tidak langsung ditampilkan pada halaman.

- `<title>` digunakan untuk memberikan judul pada halaman yang akan ditampilkan pada tab browser.

- `<body>` digunakan untuk menampung seluruh isi halaman web yang akan ditampilkan kepada pengguna.

**## 3. Formatting Text**

Penjelasan


Pada praktikum ini saya mempelajari cara mengatur tampilan teks menggunakan beberapa tag HTML. Formatting text digunakan untuk memberikan penekanan atau membedakan tampilan teks tertentu pada halaman web.
<b> digunakan untuk membuat teks menjadi tebal (bold).
<strong> digunakan untuk menunjukkan teks yang memiliki penekanan atau kepentingan.
<i> digunakan untuk membuat teks menjadi miring (italic).
<em> digunakan untuk memberikan penekanan pada teks, biasanya ditampilkan miring.
<u> digunakan untuk memberikan garis bawah pada teks.
<mark> digunakan untuk menyorot atau memberi highlight pada teks.
<small> digunakan untuk membuat ukuran teks menjadi lebih kecil.
<del> digunakan untuk menunjukkan teks yang dicoret.
<sub> digunakan untuk membuat teks menjadi subscript, yaitu berada sedikit di bawah teks normal.
<sup> digunakan untuk membuat teks menjadi superscript, yaitu berada sedikit di atas teks normal.

Hasil dari praktikum ini adalah teks pada halaman web dapat ditampilkan dengan berbagai format sesuai dengan tag HTML yang digunakan, seperti teks tebal, miring, bergaris bawah, disorot, dan format teks lainnya.

**## 4. Membuat Hyperlink**


Penjelasan


Pada praktikum ini saya membuat hyperlink atau tautan menggunakan HTML. Hyperlink digunakan untuk menghubungkan halaman web dengan halaman lain, website lain, atau alamat tertentu yang dapat dikunjungi oleh pengguna.
<a> digunakan untuk membuat hyperlink atau tautan.
href merupakan atribut yang digunakan untuk menentukan alamat tujuan dari hyperlink.
Teks yang berada di antara <a> dan </a> merupakan teks yang dapat diklik oleh pengguna.
</a> merupakan tag penutup dari hyperlink.

Contoh penggunaan:
<a href="halaman2.html">Halaman 2</a>

Penjelasan

Penjelasan

**## Jawaban Pertanyaan**
**1. Apa perbedaan antara tag, elemen, dan atribut pada HTML?**
Tag penanda HTML yang digunakan untuk menentukan jenis atau fungsi suatu bagian, contoh <p>.
Elemen: keseluruhan bagian HTML yang terdiri dari tag pembuka, isi, dan tag penutup, contoh <p>Hello</p>.
Atribut: informasi tambahan yang memberikan pengaturan atau keterangan pada sebuah tag, contoh href pada <a href="...">.

**2. Apa perbedaan <p> dengan <br>?**
<p> digunakan untuk membuat paragraf baru.
<br> digunakan untuk membuat pindah baris tanpa membuat paragraf baru.

Contoh:

<p>Ini paragraf pertama.</p>
<p>Ini paragraf kedua.</p>

Sedangkan:

Ini baris pertama<br>
Ini baris kedua
**3. Apa fungsi atribut href pada tag <a>?**
Atribut href pada tag <a> berfungsi untuk menentukan alamat atau tujuan yang akan dibuka ketika link diklik.

Contoh:

<a href="halaman2.html">Halaman 2</a>
**4. Apa perbedaan hyperlink internal dengan eksternal?**
Hyperlink internal: mengarah ke halaman atau bagian lain yang masih berada dalam website yang sama.
Hyperlink eksternal: mengarah ke website lain di luar website yang dibuat.

Contoh:

<a href="halaman2.html">Halaman 2</a> <!-- internal -->
<a href="https://www.google.com">Google</a> <!-- eksternal -->

**6.Apa perbedaan penggunaan <ul> dan <ol>?**
<ul> (unordered list) digunakan untuk membuat daftar tanpa urutan, biasanya menggunakan tanda titik (•).
<ol> (ordered list) digunakan untuk membuat daftar berurutan, biasanya menggunakan angka (1, 2, 3).

Contoh:

<ul>
  <li>Apel</li>
  <li>Jeruk</li>
</ul>

<ol>
  <li>Pertama</li>
  <li>Kedua</li>
</ol>

**7. Apa yang terjadi jika path gambar pada atribut src salah?**
Jika path gambar pada atribut src salah, maka gambar tidak akan tampil di halaman web. Browser biasanya akan menampilkan ikon/gambar rusak.

Contoh:

<img src="images/salah.jpg" alt="Foto Profil">

**8.Mengapa struktur heading h1 sampai h6 perlu digunakan secara terstruktur?**
Struktur heading <h1> sampai <h6> perlu digunakan secara terstruktur agar isi halaman lebih rapi dan mudah dipahami, baik oleh pengguna maupun mesin pencari.

<h1> → judul utama
<h2> → subjudul
<h3> → bagian dari <h2>, dan seterusnya.

**9.Apa fungsi komentar <!-- ... --> dalam kode HTML?**
Komentar <!-- ... --> digunakan untuk memberikan catatan atau keterangan di dalam kode HTML yang tidak ditampilkan pada halaman web.

Contoh:

<!-- Ini adalah judul utama -->
<h1>Belajar HTML</h1>

**10.Apa fungsi deklarasi <!DOCTYPE html> pada dokumen HTML?**

<!DOCTYPE html> berfungsi untuk memberi tahu browser bahwa dokumen menggunakan standar HTML5, sehingga browser menampilkan halaman sesuai standar HTML5.
